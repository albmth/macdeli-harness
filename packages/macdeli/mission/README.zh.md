# @macdeli/dsh-mission

[English](README.md) | 中文

## 概述

在重启后保留一个持续研究使命，通过 Harness 原生目标和计划继续有用工作。

所有者通过本地 Unix socket 控制暂停与恢复；状态包含使命 Agent 实际可见的工具。

<a id="use-this-package"></a>
## 使用此包

[MacDeli 配置](../profile/cordis.patch.yml)提供使命配置和必需的预算服务。

[实现](src/index.ts)使用原生会话、投影、目标和计划，不增加另一个 agent loop（智能体循环）或调度器。

`work_select` 在绑定原生目标前记录有界问题、理由、备选方向、预期结果和停止条件。

`work_checkpoint` 保留规格、命令、输入身份和进度。

`work_finish` 通过结论与证据引用记录正面、负面、无定论或失败的工作，然后选择另一个有用方向。

即使当前投影选择新任务，旧工作仍保留在仅追加的 Session 事件中。

已发布产物仍是独立且不可变的证据；模型结论不等于评估器认证。

原生目标 Round 的初始分配可配置。

`work_extend` 在同一任务内记录实质理由和额外 Round，保留任务身份、证据与延期历史。

耗尽分配后允许一次明确的重新评估 Round，用于完成、放弃或说明延期理由。

未使用该重新评估机会时会放弃有界任务，并选择新方向。

工作机进程超时与模型累计额度分别执行。

<a id="recovery"></a>
## 恢复

原生请求重试不再处理临时提供方错误后，插件持久保存至多两次计划探测，通常分别在五分钟与三十分钟后进行。

重启保留探测次数和下次唤醒时间。

模型成功输出会结束该故障事件。

预算、认证和配置失败从不安排自动探测。

未处理的设置或插件轮次失败会以所有者故障停止继续执行，包括首次模型 Round 之前发生的失败。

所有者恢复会清除使命故障，但不改变支出授权或累计账本。

定时等待到期后恢复同一任务。

暂停在重启后保留，并阻止模型准入。

计划发生身份在准入前提交，防止重复提醒两次准入同一次唤醒。

启动会协调被中断的工作选择、目标绑定和已记录的延期。

基础 `session-checkpoint-policy` 在效果发生前 flush 原生工具调用与模型请求；使命还会 flush 自身状态转换。

<a id="model-experience"></a>
## 模型体验

### 使命工具与继续执行

#### 模型看到的内容

`work_status` 与使命工具返回带修订号的任务状态、检查点和证据引用，原生目标与提醒提供下一条指令；[源代码](src/index.ts)拥有相关声明。

#### Token 影响

工具声明、任务响应与继续执行消息消耗上下文；持久等待与所有者暂停不准入思考请求。

#### KV Cache 影响

新结果与继续执行消息追加到 Session 历史，不替换此前消息。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 已发布产物的完整性不认证模型的经济结论或数值评估。
- 原生 Round 分配可以延长；独立的累计财务额度仍然适用。
